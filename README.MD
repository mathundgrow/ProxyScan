# ProxyScope

Небольшой проект на Python для поиска и проверки SOCKS5-прокси.

Программа берёт список прокси из интернета, проверяет их и сохраняет те, которые работают и подходят по заданным условиям

### Чо делает программа?

- скачивает список прокси
- проверяет несколько прокси одновременно
- проверяет, меняется ли внешний IP
- Определяет страну и город прокси
- отсеивает прокси из России
- отсеивает медленные прокси (можно настроить чувак!)
- сохраняет рабочие прокси в TXT-файл
- создает отчёт с результатами проверки

### че используется?

- Python
- Requests
- ThreadPoolExecutor
- IP-API

### если хочешь запустить:

скачай проект:

```bash
git clone https://github.com/USERNAME/proxy-scope.git
cd proxy-scope
```

создай виртуальное окружение:

```bash
python3 -m venv .venv
source .venv/bin/activate
```

Установи библиотеку:

```bash
pip install "requests[socks]"
```

Запусти программу:

```bash
python main.py
```

### Результ

После запуска программа создаст два файла:

- `working_proxies.txt` — список подходящих прокси.
- `proxy_report.txt` — подробная информация о результатах проверки.

### Важно

Используются публичные прокси, поэтому с осторожностью пользуйся приложухой, а то там какие то данные крадутся чуть-чуть
